# Security Policy

The **Discipline Planner** project and maintainers at **[SabutayCrafts](https://github.com/SabutayCrafts)** take software security and user privacy seriously.

---

## 🛡️ Supported Versions

We provide security updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## 🔒 Reporting a Vulnerability

If you discover a security vulnerability or potential exploit within **Discipline Planner**, please report it privately so we can resolve the issue before public disclosure.

### How to Report

1. **Email Privately**: Send an email to **sabubdlzad@gmail.com** with the subject line:
   `[SECURITY VULNERABILITY] Discipline Planner`
2. **Include Details**:
   - Description of the vulnerability and its potential impact.
   - Exact steps or proof-of-concept (PoC) to reproduce the issue.
   - Any affected device models, Android versions, or browser environments.
   - Proposed remediations or patches, if available.

### What to Expect

* **Initial Response**: We will acknowledge receipt of your vulnerability report within **48 hours**.
* **Investigation & Assessment**: We will verify the finding and determine its severity level within **5 business days**.
* **Remediation**: Once verified, we will work promptly to prepare and test a fix.
* **Public Disclosure**: After a security patch has been released, we will coordinate public disclosure and provide appropriate credit to the reporter (unless you prefer to remain anonymous).

### Guidelines

* **Do not open public GitHub issues** to report potential security vulnerabilities.
* Give the maintainers reasonable time to address the issue before sharing any information publicly.
* Test against your own builds and local instances; do not attempt unauthorized attacks or denial of service against other community members.
